# 🔥 Featured Projects

## 📬 FaultyMail

### Production-oriented Distributed Email Queue

A distributed asynchronous email system designed to decouple HTTP requests from email processing.

**Architecture**

```text
Client
  │
  ▼
Express API
  │
  ├──────► PostgreSQL
  │
  ▼
Redis / BullMQ
  │
  ▼
Background Worker
  │
  ├──► SMTP
  │
  └──► HTTP Mail API
        │
        ▼
      Email
```

### Highlights

- ⚡ Asynchronous email processing
- 🔄 BullMQ job queues
- 🧱 PostgreSQL persistence
- 🚨 Failed-job handling & Dead Letter Queue
- 🔁 Retry with exponential backoff
- 📊 React monitoring dashboard
- 📦 Dockerized services
- 🌐 SMTP + HTTP mail delivery
- ☁️ Deployed across multiple cloud services

**Tech:** `Node.js` `Express` `PostgreSQL` `Redis` `BullMQ` `React` `Docker`
